## ⚙️ How to Run

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/ParthWadile/JAVA-.git
```

### 2️⃣ Navigate to the Repository

```bash
cd JAVA-
```

### 3️⃣ Compile a Java Program

```bash
javac FileName.java
```

### 4️⃣ Run the Java Program

```bash
java FileName
```

> 💡 Replace `FileName` with the actual Java filename and class name.
